# Omar Khodor — Portfolio

Personal portfolio built with React + Vite, deployed to GitHub Pages at
https://notok18.github.io/Notok18/

```bash
npm install
npm run dev     # local dev server
npm run build   # production build into dist/
```

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds and publishes to Pages.
Content lives in `src/data.jsx`.
